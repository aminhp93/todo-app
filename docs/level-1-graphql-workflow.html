GraphQL

Query vs Mutation

GraphQL không dùng HTTP verb để phân biệt đọc/ghi — tất cả đi qua POST. Query nghĩa là đọc, Mutation là ghi; ranh giới do bạn tự đặt tên trong schema, không phải quy ước cứng.

todo.graphql
GraphQL

Client tự chọn field

REST luôn trả nguyên object. GraphQL để client viết { todos { id title } } thì server chỉ trả đúng 2 field — hết over-fetching, đổi lại resolver phải tự map field (created_at → createdAt).

todo.resolver.ts — toGraphTodo()
GraphQL

Error luôn HTTP 200

GraphQL trả 200 kèm mảng errors trong body kể cả khi có exception — đã thấy thật khi test lúc Postgres chưa chạy: ECONNREFUSED nằm trong errors[], không phải status 500 như REST.
